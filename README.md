# 网课视频自动切换

Windows 本机鼠标宏：用屏幕截图和 OCR 读取播放器的“当前时长/总时长”，自然播完后点击“下一个视频”，等待下一节计时重置，再点击播放。程序不向网页注入 JavaScript，也不调用课程接口。无法保证适用于所有播放器；页面出现测验、验证码或无法确认状态时会停止。

## 准备

1. 安装 **Windows 版 Python 3.12（64 位）**。不要使用 MSYS2 Python；本项目依赖 Windows 版 ONNX Runtime。
2. 在此目录运行：

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

   若没有 `py` 启动器，请把第一行换成 Windows 版 Python 3.12 的完整路径。
3. 在浏览器登录课程，打开一个**正在播放**的视频。将浏览器放在主显示器，保持窗口大小、位置和网页缩放固定。运行期间不要遮挡浏览器或锁屏。

## 标定与运行

```powershell
.\.venv\Scripts\python.exe main.py calibrate
.\.venv\Scripts\python.exe main.py dry-run
.\.venv\Scripts\python.exe main.py run
```

首次只需运行一次 `calibrate`，成功后位置会写入项目目录的 `config.json`。以后直接运行 `run`（或 `dry-run`），程序会读取该文件，不会再次要求标定。只有浏览器窗口位置、大小或屏幕分辨率变化时才需要重新标定。

标定会先冻结一张浏览器截图。按 Enter 后**点击课程浏览器使其显示在最前面**，再把鼠标放在控制栏空白处；倒计时结束时程序会在该处轻移鼠标，让自动隐藏的控制栏重新显示。截图出现后拖框圈住完整的计时文字（例如 `10:11/10:11`），上方立即显示 OCR 结果。识别成功后按 Enter 确认，Esc 可重新截图。随后逐项把鼠标放到控制栏空白处、下一节按钮和播放按钮，每次按 Enter 后有 5 秒切回浏览器。运行时程序也会在每次读取计时前轻移鼠标，避免控制栏隐藏。最后还会验证一次实时计时，成功后才保存 `config.json`。

`dry-run` 会一直观察视频，直到本应切换的时刻，仅打印预期点击并退出。确认识别准确后再使用 `run`。每次启动都有 5 秒切回课程窗口。程序每 2 秒检查一次计时；必须连续两次看到当前时间到达总时长才会切换。

如果启动时视频已暂停，计时约 10 秒不前进后会尝试点击一次播放；播放中途停住则等待约 20 秒后尝试一次。点击后 12 秒内仍没有进度就停止。悬停和按钮移动会在标定位置附近对 X、Y 分别作小范围随机偏移，点击点仍会检查是否位于课程窗口；这不保证平台不会识别自动操作。

按 **Ctrl+Alt+Q** 可紧急停止；也可把鼠标移至主屏幕左上角触发 PyAutoGUI 的安全停止，或关闭终端。浏览器失焦、窗口移动、计时消失超过 15 秒、切换失败或尝试播放后仍没有进度时，程序会停止并发出提示音。对验证码和测验只做保守的画面文字识别；无法保证识别所有样式，遇到此类页面请自行接管。

标定期间程序按鼠标所指位置识别课程窗口；正式运行仍要求浏览器在前台，并会在每次点击前确认按钮坐标仍指向该窗口。

课程末尾若“下一节”按钮不可用，计时不会重置，程序在 20 秒后停止。若平台在末尾循环跳回第一节，仅凭计时无法判断课程身份，应手动停止。

## 测试

纯逻辑测试无需安装桌面依赖：

```powershell
py -3.12 -m unittest discover -s tests -v
```

桌面集成检查需要在实际课程页面完成：标定成功后先运行 `dry-run`，再使用一个接近播完的视频运行 `run`，核对只点一次下一节、再点一次播放，以及最后一节或弹窗时停下。
